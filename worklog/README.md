# Work log

This folder records **what was done**, **when**, and **why** for Vulcan Voyage.

It is not a product spec. Specs live in `.docs/`. The landing-page build plan lives in `.docs/07.landing-page-phases.md`.

---

## How to log

1. Create a new file: `YYYY-MM-DD-short-slug.md`
2. Add a row to `INDEX.md` (newest first)
3. Use the template below

One file per session of work, not per tiny edit. If several tasks happen in one sitting with one objective, keep them in the same entry.

---

## Entry template

```markdown
# [Short title]

- **Date:** YYYY-MM-DD
- **Time:** HH:MM–HH:MM (timezone)
- **Phase:** 0–7 or n/a (see `.docs/07.landing-page-phases.md`)
- **Objective:** One sentence — what this work was for
- **Status:** done / in progress / blocked

## What was done

- …

## Outcome

- …

## Next

- …
```
