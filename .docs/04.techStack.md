# VULCAN VOYAGE — TECH STACK

**Locked for V1 landing page:** 2026-10-08 (Phase 1)

The stack is chosen to match the design system: token-first CSS, Inter as the starting typeface, Lucide later for sparse icons, and a simple single-page App Router site.

---

## Runtime

| Layer | Choice | Why |
|-------|--------|-----|
| Framework | **Next.js** (App Router) | Single-page site with file-based routing, `next/font` for Inter, good defaults for a public marketing page |
| UI | **React** + **TypeScript** | Design system already assumes React (`Lucide React`); TypeScript for a small, durable component set |
| Styling | **CSS custom properties** + global CSS + CSS modules | Tokens in `.docs/05.designsystem.md` map 1:1. No Tailwind — avoids a SaaS/utility look fighting the editorial system |
| Type | **Inter** via `next/font/google` | Starter typeface in the design system; final grotesk can swap later without a restack |
| Icons | **Lucide React** | Named in the design system; currently used for the mobile menu control only |
| Motion | CSS transitions for reveals; **Lenis** for page smooth-scroll | Durations and easing are tokenised (150–600ms, `ease-vv`). Lenis respects `prefers-reduced-motion` |

---

## Layout primitives (this phase)

- `Container` — max 1440px, responsive gutters 20 / 40 / 64
- `Section` — semantic `<section>` with optional `id` for in-page nav
- `Grid` — 12 columns, 24px gutter (used when a section needs it)

Breakpoints:

```text
Mobile:        < 640px
Tablet:        640–1024px
Desktop:       1024–1440px
Large desktop: > 1440px
```

---

## What we are not using in V1

- Tailwind / shadcn-style card systems
- A component marketplace UI kit
- CMS (copy is locked in `08.phase-0-content-lock.md`)
- Auth, dashboards, chat widgets
- 3D / WebGL for decoration
